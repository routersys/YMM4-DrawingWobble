# DrawingWobble for YMM4

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![.NET](https://img.shields.io/badge/.NET-10.0-purple.svg)](#)
[![Release](https://img.shields.io/github/v/release/routersys/YMM4-DrawingWobble.svg)](https://github.com/routersys/YMM4-DrawingWobble/releases)

---

YukkuriMovieMaker4（YMM4）上で動作する、映像を手描きアニメのように細かく揺らす映像エフェクトプラグインです。
映像の各画素を位置ごとに決めた向きと量だけずらし、同じゆれを数フレーム保ってから次のゆれへ切り替えます。
色や不透明度が変わる輪郭の近くだけを揺らすこともできるため、静止画や図形や文字の輪郭を手描きの動画のように動かせます。

## 概要

本プラグインは YMM4 の映像エフェクトとして動作します。エフェクトの一覧の「アニメーション」と「加工」に「作画ゆれ」として表示されます。映像の各画素を、その位置に応じて決めた向きと量だけずらした先の色で描き直します。ずらす向きと量は、「ゆれの粗さ」の間隔で並べた格子の点ごとに乱数から決め、点と点の間は滑らかにつなぎます。

乱数は「シード」と、アイテムの先頭から数えたコマの番号と、画素の位置だけから決まります。時刻や描画のたびに変わる値を使わないため、同じフレームは何度描いても同じ結果になります。

処理はピクセルシェーダーで行い、GPU で描画します。設定はアイテムのエフェクトの項目としてプロジェクトに保存します。プラグイン自体の設定ファイルはありません。

画面の表示は日本語のほか、英語、簡体字と繁体字の中国語、韓国語、スペイン語、アラビア語、インドネシア語に対応します。

## インストール方法

1. [Releases](https://github.com/routersys/YMM4-DrawingWobble/releases/latest) ページから最新のプラグインファイル（`.ymme`）をダウンロードしてください。
2. YMM4 が起動していないことを確認し、ダウンロードしたファイルを実行してインストールします。
3. YMM4 を起動し、アイテムの映像エフェクトから「アニメーション」か「加工」の「作画ゆれ」を追加します。
4. 既定の設定では、輪郭の近くが 2px までずれ、そのゆれが 3 フレームごとに切り替わります。「ゆれ幅」と「輪郭への集中」で見た目を調整します。

## 主な機能

### 1. ゆれ

「ゆれ幅」は、画素をずらす最大の距離です。縦と横のそれぞれに、この距離までずらします。0px にすると映像をそのまま通します。

「ゆれの粗さ」は、ずらす向きが切り替わる間隔です。この間隔で並べた格子の点ごとにずらす向きと量を決め、点と点の間は滑らかにつなぎます。小さくすると細かく波打ち、大きくすると広い範囲が同じ向きに動きます。格子は、このエフェクトに入る映像の中心を基準に並べます。

「ゆれ幅」と「ゆれの粗さ」は、YMM4 のアニメーションの設定で時間に沿って変えられます。

### 2. コマ打ち

「コマ打ち」は、同じゆれを保つフレーム数です。アイテムの先頭から数えて、このフレーム数ごとにゆれの模様を切り替えます。1 にすると毎フレーム切り替わり、2 か 3 にすると手描きアニメのコマ打ちに近い動きになります。

「シード」は、ゆれの模様の並びを決める値です。同じ設定のアイテムを複数置くときに、シードを変えると別々の動きになります。

「コマ打ち」と「シード」はアニメーションできません。

### 3. 輪郭への集中

「輪郭への集中」を上げると、色や不透明度が変わる境目の近くだけを揺らします。各画素について、「輪郭の範囲」の距離だけ離れた 8 方向の色を自分の色と比べ、差が大きいほど強く揺らします。差が無い平らな部分は「輪郭への集中」の分だけゆれが弱まり、100% では動きません。0% にすると、輪郭に関わらず全体を一様に揺らします。

輪郭の判定には不透明度の差も使います。透明な背景の上に描いた線や図形や文字は、その縁が輪郭として揺れます。

「輪郭の範囲」と「輪郭への集中」は、YMM4 のアニメーションの設定で時間に沿って変えられます。

### 4. 映像の外形

揺れた映像は、元の外形から「ゆれ幅」の分だけ外へはみ出せます。エフェクトの出力範囲は、「ゆれ幅」を切り上げて 2px を足した分だけ広げます。広げる量は 4096px が上限です。元の映像の外を参照することになった画素は透明になります。

## パラメータ一覧

| 項目 | 既定値 | 内容 |
|---|---|---|
| ゆれ幅 | 2px | 画素をずらす最大の距離です。0px から 4096px までで、0px にすると映像をそのまま通します。 |
| ゆれの粗さ | 60px | ずらす向きが切り替わる間隔です。1px から 4096px までです。 |
| コマ打ち | 3 | 同じゆれを保つフレーム数です。1 以上の整数です。 |
| シード | 0 | ゆれの模様の並びを決める値です。0 以上の整数です。 |
| 輪郭の範囲 | 12px | 輪郭を調べるときに、自分の色と比べる相手までの距離です。0px から 4096px までで、0px にすると全体を一様に揺らします。 |
| 輪郭への集中 | 100% | 輪郭の近くにゆれを集める度合いです。0% から 100% までで、0% にすると全体を一様に揺らします。 |

「ゆれ幅」「ゆれの粗さ」「コマ打ち」「シード」は「ゆれ」のグループに、「輪郭の範囲」「輪郭への集中」は「輪郭」のグループにあります。

---

## 制限事項

- 輪郭の判定は色と不透明度の差で行います。差が小さい輪郭は、その差の分だけ弱く揺れます。
- 「コマ打ち」はフレーム数で数えるため、プロジェクトのフレームレートを変えると、同じゆれを保つ時間が変わります。
- 揺れた映像は元の外形の外へ出るため、出力範囲は元の映像より大きくなります。
- AviUtl の exo ファイルへの書き出しには対応していません。

## 注意事項

- 更新の確認: アイテムに作画ゆれを追加するか、作画ゆれを含むプロジェクトを開いたときに、YMM4 の起動ごとに一度だけ GitHub のリリースを確認し、新しいものがあればメッセージで知らせます。
- 不具合の自動送信: 想定していない例外が起きたときは、その内容を開発者へ自動で送信します。内容は「不具合の報告」に書いています。
- 本プラグインを使用する前に、YMM4 プロジェクトファイルのバックアップを作成することを推奨します。

## 不具合の報告

本プラグインは、想定していない例外が起きたときに、その内容を開発者へ自動で送信します。同意は求めず、常に送信します。

送信する情報は次のとおりです。

| 種類 | 内容 |
|---|---|
| 例外 | 型の完全名、メッセージ、スタックトレース |
| 発生位置 | モジュール名、関数名、ファイル名、行番号 |
| プラグイン | アセンブリ名、バージョン |
| 実行環境 | OS の名前とバージョン、.NET のバージョン、CPU のアーキテクチャ、論理プロセッサ数 |
| 識別子 | YMM4 の起動ごとに決まるセッション識別子、報告ごとの識別子 |

メッセージとファイル名は、送信の前に置き換えを通します。置き換えるのは、Windows のユーザー名、ユーザーフォルダー、AppData のパス、マシン名、ドメイン名、メールアドレス、IPv4 アドレスです。送信元の IP アドレスは受信側へ渡す手前で取り除いています。

映像の中身とプロジェクトの内容は送信しません。継続して個人を追跡する識別子も持ちません。セッション識別子は YMM4 を起動し直すと別の値になります。

送信するのは想定していない例外だけです。YMM4 が本プラグインのエフェクトを作るとき、フレームごとに更新するとき、破棄するときと、Direct2D がシェーダーの定数を書き込むときに起きた例外を報告し、その後は YMM4 へそのまま渡します。画面の操作やバックグラウンドの処理で未処理になった例外も報告しますが、本プラグインのコードが関わる例外に限ります。本プラグインの外で起きた例外は送信しません。

次の失敗は送信しません。

| 種類 | 例 |
|---|---|
| 効果をかけないだけで済ませるもの | Direct2D がエフェクトを作れず、映像をそのまま通したとき |
| 更新の確認の通信の失敗 | GitHub へ接続できない |

送信できなかった報告は YMM4 のユーザーフォルダーへ退避し、次回の起動時に送り直します。送信も再送も非同期に行うため、起動と描画が遅くなることはありません。

実装は [YMM4-Telemetry](https://github.com/routersys/YMM4-Telemetry) をサブモジュールとして取り込んでいます。
